    How to convert Photoshop brushes to Infinite Painter

    1. Choose one or several Photoshop brush files (.abr) at the top of this page, or drop them onto it.
    2. Press Convert brushes. The conversion runs on your own device and takes a few seconds per file.
    3. Download the .przp pack of each file.
    4. Import the .przp into Infinite Painter. The brushes arrive in a new folder named after the pack.

    For each file, the page tells you how many brushes converted completely, how many only partially, and which Photoshop feature was lost.

    Why this ABR to PRZP converter exists

    Most brush packs shared or sold online are made for Adobe Photoshop and come as .abr files. Infinite Painter has its own brush format (.prbr for one brush, .przp for a pack), so those packs cannot be used there as they are. I draw as well as code, and I built this converter to carry Photoshop brushes over to Infinite Painter, then made it free for anyone with the same problem.

    It converts more than the shape of the brush tip. Spacing, angle, scatter, jitter, pressure and tilt dynamics, textures, color jitter and wet edges are translated to the closest Infinite Painter settings, so a converted brush behaves like the original instead of being a plain stamp.

    Questions

    Is it really free?

    Yes. There is no account, no limit and no paid version. The code is open source and in the public domain (CC0), available on GitHub.

    Are my brushes uploaded somewhere?

    No. This page has no server behind it: your files are read and converted inside your browser, and nothing is stored. Download your packs before closing the tab, because they are gone once you leave.

    Which brush files can it read?

    Brushes saved by Photoshop 7 or newer (ABR versions 6 to 10). Very old .abr files are not supported. A few Photoshop features have no equivalent in Infinite Painter and are dropped: “Fade” controls, foreground/background color dynamics, and the mixer and smudge tools.

    Can I convert a whole folder of brushes at once?

    You can pick many files in one go on this page. To convert entire folders automatically, use the command-line version from the GitHub repository.

    A brush looks wrong after import. What can I do?

    Open an issue on GitHub and say which brush pack it was. Not every setting has been checked by hand yet; the table above shows what has been tested.
